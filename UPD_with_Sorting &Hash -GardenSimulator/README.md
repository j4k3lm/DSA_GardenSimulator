# Python-Based Garden Simulator (v0.10.2)
DSA project: Python OOP, Stack, Queue, 2D list, Hierarchical Tree, Tree Traversal (BFS, Preorder, Inorder, Postorder), Binary Search Tree and Node Mutation.
Stack: HTML5/DOM/Vanilla JS, Tailwind (CDN), Lucide (CDN), Pyodide.

## Run
Open this folder in VS Code, install the **Live Server** extension, right-click `index.html` > *Open with Live Server*.
Code Editor tab > **Run All 1-10** > play. Play: pick a seed (1-9,0), click tiles; Water (W), Spray (E), Inspect (R), Harvest All (H), Prune Dead (P), Sell (S), Solar Boost (B), Undo (U). DSA Lab tab shows the trees.

## Git / GitHub
First time:
```
git init
git add .
git commit -m "v0.10.2: AVL, sorting, hash tables and English UI"
git tag v0.10.2
git branch -M main
git remote add origin https://github.com/<your-username>/garden-simulator.git
git push -u origin main --tags
```
Already pushed an older version? Just update it:
```
git add .
git commit -m "v0.10.2: AVL, sorting, hash tables and English UI"
git tag v0.10.2
git push
git push --tags
```
Paste the repository link in Section 7 of `docs/JOURNAL.md`.
